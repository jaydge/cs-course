# Week 1 Teacher Guide

## 1. Header

- **Week:** 1 of 32
- **Unit:** 1, Thinking Like a Computer Scientist
- **Theme question:** How does a button press become something useful?
- **Session length:** 2 hours

## 2. Learning objectives

By the end of the session, each student can:

- Operate the laptop: use the trackpad, right-click (two-finger tap or Control-click on a Mac), and switch between open apps.
- Create a folder, save a file into it, and find it again. This is the single most important outcome.
- Open Thonny, type and run one line of Python, and save the program file into their folder.
- State the course's driving question and explain, in plain terms, what "opening the black box" means.
- Understand two class norms: the no-AI-until-taught policy, and the "stuck" protocol.

## 3. Where this sits

This is the first session, so it opens the course's driving question and builds the computer-fluency floor that everything else stands on. Because there is no pre-course prep and some students have only used iPads, Week 1 front-loads laptop and file-system basics. The real Python ramp (variables, input, functions) begins in Week 2. This session sets up all of Unit 1.

## 4. Materials and setup

- Apple IIe powered on and sitting at the BASIC prompt, with room for students to gather around it.
- Each student's laptop charged, on the desk, logged in to the student account, with Thonny already installed from the golden image.
- A projector or shared screen to demonstrate Finder and Thonny.
- Printed, one per student: the readiness diagnostic (Part A checklist and Part B questions, from the Younger-Student Readiness and Prep guide) and the Week 1 homework handout.
- Whiteboard and markers, with the theme question written large.
- Optional: index cards and a jar of peanut butter, bread, and a plate if you run the Robot Chef energizer.

Note on accounts: this session does not create student accounts in class. Account setup is homework done with a parent, because it involves age and consent rules. This assumes you have already sent parental-consent forms home. The parent syllabus covers that.

## 5. Pre-class prep checklist

- Confirm the Apple IIe boots to BASIC and test the `10 PRINT "HELLO" / 20 GOTO 10 / RUN` program. (15 min)
- On each student laptop, confirm it powers on, logs in, and Thonny opens cleanly. (about 5 min per laptop)
- Print the readiness diagnostics and homework handouts, one per student. (10 min)
- On the demo machine, create a sample folder and file so you can model saving quickly. (5 min)
- Write the theme question and the day's plan on the board. (5 min)
- Have a spare laptop ready in case one will not cooperate. (5 min)

## 6. Minute-by-minute class flow

### Segment 1: Welcome and the big question (0:00 to 0:20), Systems strand

- **You do:** Welcome students. Point to the theme question on the board and frame the whole year around it (see Scripts). Then gather everyone at the Apple IIe.
- **You do:** Boot it, and let every student type `10 PRINT "HELLO" / 20 GOTO 10 / RUN` and watch the screen fill.
- **Students do:** Take turns at the keyboard; watch a 40-year-old computer run their command.
- **Purpose:** A low-tech, high-wonder hook that needs no laptop skill, so every student succeeds in the first ten minutes. It plants the idea that a typed command becomes something the machine does, which is the whole course in miniature.

### Segment 2: The laptop and the file system (0:20 to 1:10), the core

- **You do:** At the projector, demonstrate slowly: the trackpad, clicking, right-click as a two-finger tap, and switching apps. Then open Finder and show the sidebar, creating a folder, saving a file into it, closing it, and finding it again with Spotlight.
- **Students do:** Mirror each step on their own laptops. Create a folder named something like "CS Class" in Documents. Practice right-click. Practice switching between two windows.
- **You do:** Circulate constantly. This is where iPad-only students need the most help. Pair a confident student with a struggling one.
- **Purpose:** The file system is the skill the rest of the course assumes and the one an iPad hides. Protect this segment above everything else in the session.

### Segment 3: Stretch and transition (1:10 to 1:15)

- A short break. Reset attention before the coding segment.

### Segment 4: Your first line of code (1:15 to 1:40), Coding strand

- **You do:** Open Thonny on the projector. Type `print("hello")`. Run it. Point out that this is the same idea as the Apple IIe's `10 PRINT`, forty years apart.
- **Students do:** Open Thonny, type `print("hello")`, run it, then change the word in quotes to their own name and run it again. Save the file into the "CS Class" folder from Segment 2. Close Thonny and reopen the file from Finder.
- **Purpose:** A Day 1 win where students run real code and, just as importantly, save and find a real file. It ties the file system directly to programming.

### Segment 5: Diagnostic, norms, homework, wrap (1:40 to 2:00)

- **You do:** Hand out the readiness diagnostic. Walk the room for Part A while students complete Part B in writing. Collect it; you will use it to plan support, not to grade.
- **You do:** State the two class norms briefly (see Scripts): the no-AI rule for now, and the "stuck" protocol.
- **You do:** Hand out the Week 1 homework and read through it together so nobody leaves unsure.
- **Students do:** Ask any questions; pack up.

## 7. Key scripts and analogies

- **The driving question:** "Everything we do this year answers one question: how does a button press become something useful? By June, you will be able to trace what happens from the moment you click a mouse all the way to the picture on your screen. Right now most of that is a black box. We are going to open every one of those boxes."
- **The Apple IIe tie-in:** "This computer is older than your parents' first phones, and it still does exactly what you tell it. That is the deal with every computer: it does what you say, not what you mean."
- **The file system:** "Think of the folders as drawers in a filing cabinet. A file has a name and it lives in a specific drawer. On an iPad, the computer hides where things live. Here, you are in charge of where things go, and that is a good thing, because you will always be able to find your work."
- **Right-click:** "The two-finger tap is how you ask the Mac, what can I do with this? Get in the habit of it."
- **Saving:** "Saving is deliberate. You choose the name and you choose the place. Nothing saves itself here, so we always know where our work is."
- **The no-AI norm:** "You will learn to use AI tools later in this course, on purpose, because knowing how to use them well is a real skill. But for now, everything you write, you write yourself. It is like learning arithmetic before you are handed a calculator. The point is for your brain to learn to do it."
- **The stuck protocol:** "Being stuck is normal and it is where learning happens. When you are stuck: try for a few minutes, check your notes, ask a classmate, then ask me. In that order."

## 8. Differentiation

- **Younger or brand-new students:** Pair them with a more experienced student for Segment 2. Give the file-system steps as a printed checklist to follow at their own pace. It is completely fine if a student only reaches "save and find a file" by the end of the session and does the Thonny code next week. Do not rush them past the file system.
- **Extensions for advanced or AP-track students:** As they finish Segment 2 early, let them explore Thonny further (print with arithmetic, several lines), start the optional typing goal, or help a partner. AP-track students can begin Project STEM's first unit at home this week; mention it to them individually.

## 9. Common pitfalls

- **The intro runs long.** This is the most likely problem. If Segment 2 eats the clock, move the Thonny segment to the start of Week 2. Protect the file-system core over everything else.
- **Account creation in class.** Do not attempt it. It needs parental consent and eats time. It is homework with a parent.
- **Trackpad and right-click confusion.** Expect this from iPad-only students. Demonstrate slowly and have them mirror you rather than telling them steps verbally.
- **A student "loses" a saved file.** This is a teachable moment, not a failure. Walk them through finding it in Finder or with Spotlight. The recovery is the lesson.
- **A laptop will not open Thonny.** Use the spare or pair the student up, and troubleshoot after class rather than holding up the room.

## 10. Homework

Light and confidence-building, appropriate for true beginners. Full details are in the student handout at `handouts/week-01-homework.md`. In summary: practice creating a folder and saving and finding a file; set up the class accounts with a parent; optional typing practice; an optional short video; and a two-to-three sentence reflection comparing the laptop to an iPad.

## 11. Assessment

Week 1 is diagnostic and foundational, so keep it low-stakes. Check that each student can create, save, and find a file by the end of the session, by observation. Collect the readiness diagnostic to plan support for the coming weeks; it is not graded. Homework is a completion check against the weekly-labs rubric (works, partly, not yet), scored generously this week given there was no pre-course prep.

## 12. AP alignment

This session touches AP CSP Big Idea 1, Creative Development, lightly, through writing and running a first program. AP-track students begin Project STEM's first unit at home this week at their own pace. No exam content is introduced, and nothing here is required of non-AP students.
