# AP CSP Topic Coverage Map

A topic-by-topic map of the AP Computer Science Principles framework (all five big ideas, 35 topics) against where our course covers them. This is the evidence for claiming high-level AP CSP coverage. Depth varies: AP-track students go deeper through Project STEM, but every AP topic is touched in the base course.

Status key: **Covered** (was already in the course), **Strengthened** (was light, now explicit), **Added** (newly folded in to close a gap).

## Computational Thinking Practices

The six practices are skills, not content topics, and the course exercises all of them by how it teaches: solution design and algorithms (the programming core and the unplugged maze), abstraction (functions, data structures, the build-the-stack arc), code analysis (debugging, testing, the pseudocode bridge), computing innovations (the "how it works" and Mystery Days), and responsible computing (the ethics unit and the AI policy). Note that Practice 6, Responsible Computing, is assessed only through the Create Performance Task, not the multiple-choice exam.

## The honest claim this supports

With the five additions above (all small: one data lab and four short concept or exercise insertions folded into existing weeks), the course touches every AP CSP topic. That supports the statement that the course covers AP CSP at a high level. It does not mean the base course goes to exam depth on every topic; Big Idea 3 is at or beyond exam depth because programming is our focus, while the Data and Impact topics are covered more lightly. AP-track students close any depth gap through the self-paced Project STEM units, which is the design already in place.
