# Week 2 Homework: Binary and Your First Real Program

This week you learned two big things: how computers store everything as 1s and 0s, and how to write a program that talks back. The homework practices both. Plan on about 30 to 45 minutes.

## 1. Binary practice

Use the card method from class (16, 8, 4, 2, 1). You can draw the five cards on paper and check boxes.

- Convert these to binary: 6, 13, 22
- Convert these to decimal: 101, 1100, 10111
- Bonus question: why is 31 the biggest number five cards can make?

Write your answers on paper or in a file saved to your CS Class folder.

## 2. Extend your greeting program

Open the greeting program you saved in class. Add one more question (anything you like) and use the answer in the final printed sentence. Then add one line that asks for a number and prints that number doubled. Remember what happens with `input` and numbers, and what fixes it.

Save it into your CS Class folder. Run it one last time to make sure it works.
